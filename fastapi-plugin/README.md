## What it does

A FastAPI engineering toolkit for Claude Code: Pydantic v2 schema design, async routing and dependency injection, the app lifespan, the SQLAlchemy / SQLModel data layer, Alembic migration safety (zero-downtime expand-contract), pydantic-settings config, security auditing, testing and async performance. It is adapter-driven: app layout, ORM, async or sync stack, migration tool and test runner are detected per project, not assumed.

It is for developers on any FastAPI codebase (sync or async; SQLAlchemy 2.0 or SQLModel; Alembic). It is opinionated about what breaks FastAPI services in production (a blocking call inside `async def`, a table model returned as a response, N+1 lazy loads and the async `MissingGreenlet` trap, unverified JWTs, wildcard CORS with credentials, autogenerated revisions applied unread, committed secrets) and stays quiet otherwise.

## Install

```
/plugin marketplace add taqat-techno/plugins
/plugin install fastapi@taqat-techno-plugins
```

## Requirements

| Requirement | Needed for | Check |
|---|---|---|
| Python 3.8+ as `python3`, `python` or `py -3` | the three hooks (stdlib only) | `python3 --version` |
| A POSIX shell (`sh`; Git Bash on Windows) | the hook launcher | `sh -c 'echo ok'` |
| A FastAPI project (`fastapi` declared as a dependency) | the bash guard fires only in one | `grep -i fastapi pyproject.toml requirements*.txt` |
| A runnable project environment | Alembic commands, the test suite | `alembic current`, `pytest --collect-only -q` |
| Optional: `pip-audit` or `safety` | `/fastapi:security --deps` | `pip-audit --version` |

## Commands

| Command | What it does | Bare invocation |
|---|---|---|
| `/fastapi:migrate [--make\|--apply\|--plan\|--check]` | Alembic safety gate: autogenerate, read the revision (and what autogenerate missed), `--sql` preview, a real `downgrade()`, confirm the target database, then upgrade. Risky changes get an expand-contract plan. | `--check` (`alembic check`, `current`, `heads`) |
| `/fastapi:scaffold [resource] [--crud\|--no-crud] [--async\|--sync]` | Scaffold a resource (ORM model, `Create`/`Read`/`Update` schemas, `APIRouter` CRUD, Alembic revision, tests). Plans the diff and waits for approval. | asks for the resource |
| `/fastapi:test [path\|--all] [--cov] [--failed] [--async] [-k EXPR]` | Runs the tests for what changed (T1, then T2) with the right client and overrides, and classifies failures. | tests the changed files |
| `/fastapi:security [path] [--deps] [--fix]` | Code and config audit for auth/JWT, authorization, injection, CORS, secrets and CVEs; severity-rated findings with fixes. `--fix` applies only unambiguous low-risk fixes. Defensive only. | full audit, report only |

The old names `/fastapi:fastapi-migrate`, `/fastapi:fastapi-scaffold`, `/fastapi:fastapi-test` and `/fastapi:fastapi-security` still work as deprecated aliases and will be removed in 0.6.0.

## Skills

Model-invoked from what you are doing; none is a slash command.

| Skill | Use when |
|---|---|
| `fastapi-routing` | Path operations, `APIRouter`, `Depends()` and yield dependencies, the app `lifespan`, `response_model`, status codes, error shaping, pagination. |
| `fastapi-pydantic` | Pydantic models, request vs response separation, validators, `from_attributes`, v1 to v2, field leaks and mass-assignment. |
| `fastapi-database` | ORM models, sessions (sync and async), engine lifecycle, `selectinload` vs `joinedload`, transactions, `MissingGreenlet`. |
| `fastapi-migrations` | Alembic autogenerate and upgrade, reviewing a revision, real downgrades, schema changes against live data, multiple heads. |
| `fastapi-config` | pydantic-settings `BaseSettings`, env-driven config, secrets, per-environment debug / docs / CORS. |
| `fastapi-security-audit` | Security review, release hardening, suspected vulnerability or leaked secret. Renders the pass/fail verdict. |
| `fastapi-testing` | `TestClient` vs `httpx.AsyncClient`, running the lifespan in tests (`LifespanManager`), `dependency_overrides`, test DB, scoped runs, flaky tests. |
| `fastapi-async-performance` | Slow or blocking routes, `def` vs `async def`, background work, caching, pool sizing, pagination at scale. |

## Agents

Read-only analyzers that return findings tables. Each has `tools: Read, Glob, Grep, Bash`. Bash is there only for read-only inspection (`alembic current/heads/history`, `alembic upgrade --sql`, `pip-audit`); the agents are instructed never to write, and the destructive-command guard still applies to anything they run.

| Agent | Use for |
|---|---|
| `alembic-migration-analyzer` | Classify unapplied revisions by lock/rewrite risk and reversibility, flag autogenerate gaps, produce an expand-contract plan. |
| `fastapi-security-auditor` | Deep defensive audit of a codebase or app; severity-rated findings with `file:line` and fixes. |
| `async-query-optimizer` | Hunt N+1s (including the async-session trap), event-loop-blocking calls, over-fetch, write loops and offset pagination at scale. |

## Hooks

| Hook | Event (matcher) | What it does | Can block? |
|---|---|---|---|
| `session_start.py` | SessionStart (`startup`) | Finds a FastAPI project (a `fastapi` dependency, or an entrypoint such as `app/main.py` or `src/<pkg>/main.py` that constructs `FastAPI(...)`) in the session directory or up to two levels below, then adds one context line: FastAPI and Pydantic versions, ORM, async driver, Alembic. Prints nothing elsewhere. | No |
| `pre_write_guard.py` | PreToolUse (`Write\|Edit\|MultiEdit`) | Advisory: a blocking call (`time.sleep`, `requests.*`, `urlopen`) inside an `async def` body (checked with `ast`, so a sync `def` is not flagged), a hardcoded secret literal in a config file (any case, with or without a type annotation, e.g. `secret_key: str = "..."`), `allow_origins=['*']` with `allow_credentials=True`, and an empty Alembic `downgrade()`. | No |
| `pre_bash_guard.py` | PreToolUse (`Bash`) | In a FastAPI project only, asks you to confirm `alembic downgrade base`, `dropdb`, `mysqladmin drop` and `DROP DATABASE` sent to a SQL client. It parses the command, so quoted text, comments, `echo`, `grep` patterns, commit messages, `--help` and offline `--sql` runs never trigger it. Advisory on `alembic stamp`. | Asks you (`permissionDecision: "ask"`); it never denies |

A FastAPI project, for the bash guard, is a `fastapi` dependency in `pyproject.toml`, `requirements*.txt`, `requirements/*.txt`, `Pipfile`, `setup.cfg` or `setup.py`, found walking up from the working directory (or a `cd` target in the command), or up to two levels below `CLAUDE_PROJECT_DIR`. Hooks fail open: bad input, a missing Python or an internal error lets the tool call through.

## Configuration

| Setting | Where | Effect |
|---|---|---|
| `destructive_guard` (boolean, default `true`) | plugin option, set in `/config` or when enabling the plugin | `false` turns off the bash guard's confirmation prompts. Advisories stay on. |
| `ALLOW_FASTAPI_DESTRUCTIVE=1` | environment of the Claude Code process, set before launching it | Same as `destructive_guard: false`. Kept for users of the 0.4 token. Writing the name inside a command no longer does anything. |
| `.claude/fastapi.local.json` | project root, created by `/fastapi:scaffold` only if you agree | Caches detected non-secret inputs (`appEntrypoint`, `routersDir`, `orm`, `asyncStack`, `migrationTool`, `settingsModule`, `testClient`, `runPrefix`, `localPackages`, `authModel`, `dbBackend`). The schema is in `commands/scaffold.md`. The legacy `.fastapi-kit.local.json` is still read. Add either to `.gitignore`. |

## Platform support

| Platform | Status |
|---|---|
| Linux, macOS | Supported. |
| Windows with Git Bash | Supported. The launcher tries `python3`, `python`, then `py -3`, and skips the Microsoft Store `python3` stub. |

## Data & privacy

- The hooks read the hook payload (the command or the file content being written) and, for project detection, file names, dependency files and candidate entrypoints in your project. They make no network calls and store nothing.
- `.claude/fastapi.local.json` is written only with your consent and holds non-secret layout data. Commands never write a secret or database URL into it.
- `/fastapi:migrate --apply` prints the target database's driver, host, port and name, never its password or full URL.
- `/fastapi:security --deps` runs `pip-audit` or `safety` if you have them; those tools query their vulnerability databases over the network.
- Nothing is sent anywhere by the plugin itself.

## Limitations

- The bash guard sees only the command text. It cannot see SQL inside a file passed with `psql -f`, a script, or an alias, and it does not stop `alembic downgrade <rev>` chains, `DROP SCHEMA` or `TRUNCATE`.
- The async check runs on the text being written; an Edit hunk that does not contain its enclosing `async def` cannot be judged, and one that does not parse falls back to a file-level check.
- The CORS check sees literal lists only; origins held in a variable are not checked.
- The plugin never runs `alembic upgrade` or a destructive command on its own; the commands stop for review by design.
- Security review is defensive: it describes vulnerabilities and fixes, never working exploits.
- Optional companions: if `agent-safety-guards` is installed, its `test-scope` skill and hook add stricter test-tier rules; `/fastapi:test` works the same without it.

Development: `python -m pytest -q -p no:cacheprovider` from this directory runs the offline suite; `python validate_plugin.py fastapi-plugin` from the repository root checks the structure.
