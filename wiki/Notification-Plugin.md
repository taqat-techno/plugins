# notification

Native desktop notifications when a Claude Code session needs you - questions, permission prompts, task completions, turn completion and API failures. Hooks only, no AI at runtime, never blocks Claude, silent no-op where no desktop notifier exists. Optional title-only mode keeps message text off the screen.
