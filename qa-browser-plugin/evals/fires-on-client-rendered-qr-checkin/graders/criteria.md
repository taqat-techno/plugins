PASS if the reply says a code rendered on the client is not proof of identity unless the server verifies a
signature, binds it to the person presenting it, and enforces expiry or single use, and proposes a
concrete runtime test such as comparing the codes of two different identities or replaying a
captured code.
FAIL if the reply only discusses QR scanning reliability, camera handling or code size, or accepts the
client-generated code as secure without asking for server-side signature, binding and expiry checks.
